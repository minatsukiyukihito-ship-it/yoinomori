# 宵ノ社 — GitHub Pages用ファイル

このフォルダーの中身をGitHubリポジトリの公開元（`main`ブランチのルート、または`docs`フォルダー）へ配置してください。ビルド作業は不要です。

## ファイル構成

- `index.html` — ゲーム画面
- `styles.css` — 画面デザイン
- `game.js` — バトル、育成、保存処理
- `assets/` — 巫女と妖怪の画像

ファイルの相対位置を保ってアップロードしてください。`index.html`をリポジトリのルートまたは`docs`に置き、GitHubリポジトリの **Settings → Pages** で公開元のブランチとフォルダーを選ぶと公開できます。進捗データはプレイヤーごとのブラウザーに保存されます。
