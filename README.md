# 宵ノ杜（よいのもり / YOINOMORI）

GitHub Pages 用の静的ゲーム一式です。このフォルダーの中身を GitHub リポジトリのルートへアップロードし、リポジトリ設定の Pages で `main` ブランチの `/ (root)` を公開元に設定してください。

現在のゲームバージョンは 1.514 です。第二段階「逢魔の森」（レベル101〜1,000）、新しい怪異12種、レベル帯に応じた装備制限と旧セーブの装備調整、格上相手の戦闘補正、重複装備の合成補正と指南タブを含みます。

プレイヤー記録はブラウザーの localStorage に保存されます。同じブラウザー・同じ端末で同じ公開 URL を使う限り、通常はゲーム更新後も記録が残ります。ブラウザーのデータ消去、別端末・別ブラウザー、保存キー変更では引き継がれません。


ゲーム計測イベント（game_start、battle_start、節目到達）を含みます。イベント送信には、公開用 index.html へのGA4タグ設定が必要です。
